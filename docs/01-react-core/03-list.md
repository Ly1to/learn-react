## 本课将包含

- 数组数据放组件外当常量，用 `map` 渲染列表。

- 排序/筛选时不能原地修改原数组（`toSorted` / `[...arr].sort()`）。
- 列表渲染单元抽成组件（在 02 的 `Card` 基础上）。
- 验收、自测题、常见错误对照。
